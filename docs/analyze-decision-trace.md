# 分析页可审计决策轨迹

分析页在一次成功检测后展示六个结构化阶段，帮助使用者回看已经返回的公开判定依据。它只消费现有分析响应，不会创建新的检测请求、模型调用、SSE、WebSocket、数据库记录或遥测。

## 阶段与字段来源

| 阶段 | 结构化字段来源 | 对外显示范围 |
| --- | --- | --- |
| 脱敏接收 | 固定的请求边界说明 | 仅说明请求已进入检测链路，不回显提交内容。 |
| 语义检测 | `semantic_severity`、`semantic_categories`、`semantic_model_id`、`semantic_latency_ms` | 模型标识仅显示最后一段公开名称。 |
| Token 观测 | `signals.length` | 只显示数值信号数量。 |
| CPD 判断 | `detector_status`、`detector_score`、`provenance.thresholds.h`、`suspicious_span` | 仅显示分数、阈值和既有异常起点位置；不显示 Token 文本或词表 Token ID。 |
| 证据融合 | `fusion_reason` 与语义/CPD 状态 | 显示固定融合策略及两路结构化关系。 |
| 处置决策 | `decision`、`risk_score` | 显示固定策略产生的最终处置。 |

## 回看与动态效果

六个阶段以 240ms 的界面播放间隔依次出现。该间隔仅用于界面呈现，不表示模型或服务端耗时。点击已经出现的阶段只切换当前展示的结构化证据，不会重新检测，也不会重新提交分析请求。

当系统启用 `prefers-reduced-motion: reduce` 时，所有阶段立即显示，并取消轨迹阶段和详情的进入动画与过渡效果。

## 隐私与边界

轨迹禁止显示原始 Prompt、攻击 suffix、Token 文本、词表 Token ID、原始模型输出、私有路径、检索词和隐藏思维链。模型路径会转换为公开名称；轨迹只展示既有响应中的脱敏结构化字段。

这是结构化审计轨迹，不包含隐藏 CoT，也不代表与任何外部安全设备联动。它不会改变语义等级、CPD 分数、异常起点、融合原因、风险分数或处置动作。
