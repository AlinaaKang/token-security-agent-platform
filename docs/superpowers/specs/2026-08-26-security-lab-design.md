# AI 安全攻防实验舱设计规格

日期：2026-08-26

## 1. 目标

在不修改现有 `/analyze`、`/events`、`/evaluation` 页面和基础检测契约的前提下，新增独立 `/lab` 实验舱。实验舱把一次检测组织成“发现异常、反事实验证、处置演练、形成报告”的可交互安全调查过程，同时为基础任务增加可解释性，为进阶任务增加知识驱动的处置能力。

实验舱服务比赛演示与研究验证，不进入现有冻结指标，不替代正式安全网关。

## 2. 非目标

- 不重新训练或替换 Qwen2.5、Qwen3Guard、Entropy-CPD。
- 不修改 `qwen25-7b-cpd-paper-v2`、冻结 profile 或既有聚合报告。
- 不声称反事实重检构成严格因果证明，只称为“反事实敏感性证据”。
- 不接入真实防火墙、EDR、工单或生产账号。
- 不把攻击原文、suffix、Token 文本或模型原始输出写入 Git、SQLite、日志、报告或截图。
- 不引入第三个大模型、图数据库或新的 GPU 常驻服务。

## 3. 产品结构

现有三个页面保持原样，主导航只增加“攻防实验舱”：

```text
/analyze       稳定基础检测
/events        正式脱敏事件
/evaluation    冻结评测
/lab           增量攻防实验舱
```

实验舱采用四阶段调查流程：

```text
场景选择
  -> 证据流水线
  -> 反事实敏感性验证
  -> 知识驱动处置沙箱
  -> 脱敏案件报告
```

### 3.1 场景选择

支持两类输入：

- 自定义 Prompt：只在请求内存中使用，浏览器本来已持有用户输入。
- 冻结样本：浏览器只发送 sample ID；服务端内部读取原文，响应继续只返回攻击族、脱敏 Token 序号和聚合证据。

首批一键场景固定覆盖普通无害、无害格式突变、直接危险、GCG、AutoDAN 和 AdvPrompter。前两类使用不含私密内容的安全合成输入；直接危险与优化攻击只引用 AutoDL 受保护场景 ID，原文不进入 Git 或场景列表响应。

### 3.2 证据流水线

按真实调用顺序展示：语义 Guard、Token 观测、Entropy-CPD、固定融合、知识检索。动画只回放记录的阶段和延迟，不伪装成并行“竞速”或模型思维链。

主要输出：

- 语义等级、类别和耗时。
- CPD 状态、分数、预测起点和耗时区间。
- 熵、NLL、CPD 累积值的同步曲线。
- 双路一致、证据冲突或证据不可用状态。
- analysis/gateway 两种固定策略的动作对照。

### 3.3 反事实敏感性验证

仅当 CPD 返回有效字符起点时启用。服务端在内存中构造 `prompt[:char_start]`，使用同一模型、system Prompt、校准和融合策略重检一次。重检不调用知识层、不写普通事件库，也不改变原结果。

返回数据只包含：

- 原始与截断后的语义等级、CPD 状态、分数、动作和延迟。
- 风险分数差、检测分数差、动作是否变化。
- `risk_reduced | unchanged | inconclusive` 三种固定解释。
- 使用的预测字符起点和校准版本。

若没有起点、起点越界、重检失败或两次 provenance 不一致，返回 `inconclusive`，保留原动作。冻结样本不得返回截断文本、真实 suffix 边界或非脱敏 Token。

### 3.4 知识驱动处置沙箱

复用现有 OWASP、MITRE ATLAS、NIST 知识卡和引用报告。根据冻结基础动作与合法 `knowledge_id` 生成可执行剧本，但工具只提供确定性 dry-run：

- `gateway_preview`：预览放行、复核或阻断策略，不修改网关。
- `soc_case_preview`：生成脱敏工单字段，不创建外部工单。
- `evidence_export_preview`：生成证据清单和哈希，不导出原文。

每个工具返回 `planned | succeeded | failed`、固定错误码、耗时和脱敏产物摘要。实验舱允许注入一次模拟失败，用于展示观察、降级和重新选择安全动作；失败时只允许转人工复核或保留原拦截，不能降低既有安全动作。

### 3.5 脱敏案件报告

案件报告汇总原始判定、反事实差异、知识引用、dry-run 结果和限制。报告不接收 Prompt、suffix、Token 文本或工具原始输出。未知引用、非法 JSON 或超时继续使用确定性模板回退。

## 4. 后端边界

新增独立模块，不向 `BasicSecurityWorkflow.analyze` 增加实验分支：

```text
app/lab/models.py
app/lab/counterfactual.py
app/lab/tools.py
app/lab/service.py
app/api/lab.py
```

`LabService` 组合现有 workflow、demo service 和 knowledge service。自定义输入和冻结 sample ID 使用互斥请求字段。核心接口：

```text
POST /api/v1/lab/runs
GET  /api/v1/lab/scenarios
POST /api/v1/lab/runs/{run_id}/tools/{tool_id}/dry-run
```

第一版 `run_id` 只存在于有界内存缓存：最多 32 个已完成 run、TTL 15 分钟，满载时淘汰最早完成项。缓存只保存结构化脱敏结果，不保存 Prompt、查询词、Token 文本或原始模型输出。进程重启后 run 消失属于正常行为。

工作流返回的 `TokenSignal` 必须在实验舱边界转换为 `LabPublicSignal`，后者只保留序号、entropy、NLL、CPD 累积值和风险值，不包含 `token_id` 或 `token_text`。工具失败注入只接受固定 dry-run 工具 ID，不接受异常文本、URL 或命令参数。

实验舱由 `TOKEN_SECURITY_LAB_ENABLED` 控制。未启用或依赖不可用时只让 `/lab` 显示明确降级，不影响现有服务健康状态。

## 5. 前端体验

新增 `LabPage`，不改 `AnalyzePage` 组件结构。页面采用工作台布局，而不是营销式卡片堆叠：

1. 顶部：场景、自定义/冻结输入、analysis/gateway 模式和开始按钮。
2. 中部：全宽证据到达时间线与同步曲线。
3. 下部三标签：`证据剖面 | 反事实验证 | 处置沙箱`。
4. 末尾：知识依据与案件报告全宽区域。知识依据使用“发布方 -> 风险域 -> 建议 -> dry-run 工具”的轻量关系带，不引入图数据库或自由生成节点。

动画使用阶段状态变化和曲线游标，支持 `prefers-reduced-motion`。手机端时间线改为纵向，宽曲线和对照表只在自身容器横向滚动。所有工具按钮明确显示“模拟执行”。

## 6. 隐私与安全不变量

- 冻结样本 API 继续只接收 sample ID。
- 实验舱响应递归拒绝 `prompt`、`suffix`、`token_text`、`token_id`、`query_text`、`raw_output` 和 `guard_raw_output`。
- 自定义 Prompt 只用于本次内存计算；日志只记录 run ID、输入哈希、字符数和固定状态。
- 反事实重检不进入正式事件表，案件报告不能被误认为原始安全事件。
- dry-run 工具没有网络客户端、凭据参数或任意命令入口。
- 模拟失败不能把 `block` 降为 `allow`，也不能推翻基础判定。

## 7. 错误处理

- 原始检测失败：实验舱 run 失败，不产生后续阶段。
- 无有效起点：跳过反事实并标记 `inconclusive`。
- 反事实失败：保留原结果，处置沙箱仍可使用原证据。
- 知识不可用：使用基础证据和确定性限制说明。
- 工具模拟失败：记录观察，动作只能保持或升级为人工复核。
- 报告失败：返回引用合法的确定性模板。
- run 过期：返回固定 `lab_run_expired`，不尝试恢复输入。

## 8. 评测与验收

### 8.1 自动测试

- 现有后端和前端测试全部保持通过。
- `/analyze` 请求、响应和审计行为回归不变。
- 反事实只使用预测起点和相同 provenance。
- 冻结样本的实验舱响应 forbidden-key 命中为 0。
- dry-run 工具不能访问网络、文件系统或子进程。
- 模拟失败不降低安全动作。
- run 缓存验证 TTL、容量、并发和过期行为。
- 前端验证完整四阶段、降级状态、键盘操作和移动端布局。

### 8.2 实验指标

新增指标与既有冻结分类指标分开展示：

- 反事实可执行覆盖率。
- CPD 告警样本的分数下降分布和动作变化率。
- 语义与 CPD 证据一致/冲突率。
- dry-run 成功率、降级正确率和 P50/P95 延迟。
- 案件报告引用有效率、模板回退率和动作不变率。
- forbidden-key、受保护原文和工具外连命中数，目标均为 0。

这些指标只描述实验舱能力，不回写 `agent-ablation-v1`，不宣称反事实分数下降等于攻击因果已被证明。

### 8.3 现场验收

三条演示路径：

1. 普通无害：双路正常，反事实不适用，放行预览。
2. 无害突变：语义安全、CPD 候选，展示证据冲突和人工复核预览。
3. 冻结优化攻击：异常定位、反事实敏感性、知识引用、阻断 dry-run 和案件报告。

在 1440x900 与 390x844 验收无重叠、无全局横向溢出、非空曲线、减弱动画和受保护文本零泄漏。

## 9. 稳定发布策略

1. 默认关闭实验舱功能开关，先完成单元和集成测试。
2. 本机以 fake runtime 验证全部状态，不调用受保护数据。
3. AutoDL 使用少量冻结 sample ID 做受保护烟测。
4. 验证基础 API、旧报告哈希和隐私扫描不变后再开启 `/lab`。
5. 任一实验舱故障均可关闭开关回退，不回滚基础任务代码。
