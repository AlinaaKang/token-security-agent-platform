# Token 侦探互动调查模式设计

**日期：** 2026-08-28  
**状态：** 已确认，待实施计划  
**适用页面：** `/challenge`

## 1. 目标

将挑战页中仅用于阶段回放的三名公仔升级为可操作的调查入口。玩家在“互动调查”模式中依次点击语义侦探、曲线侦探和小队队长；当前角色走到中央证据台，展示已经返回的真实检测字段。队长完成证据总结后，页面才解锁玩家答题区。

现有 `700ms` 检测结果回放继续作为独立的“自动演示”模式保留。互动调查是默认模式，自动演示用于比赛讲解和快速展示。

本轮目标是提升基础挑战页的交互性、可解释性和演示效果，不在同一改动中实现终极任务要求的跨域工具闭环。

## 2. 非目标

本轮不修改：

- 后端检测算法、语义模型、CPD、融合策略或 API 返回结构；
- 挑战评分、冻结样本标签或“无害格式突变”的正确动作定义；
- 知识智能体、工具计划、工具 dry-run、防火墙或 EDR；
- `/analyze`、`/lab`、事件存储、AutoDL 服务或模型部署；
- 排行榜、持久化、声音、自由拖拽或物理引擎。

“无害格式突变”的真实标签与系统当前动作分离是已知的独立问题。最终评测前应单独设计基于样本真实标签的评分标准，避免把系统误报当作标准答案；本规格不借互动改造暗改评分含义。

## 3. 用户流程

### 3.1 挑战设置

在现有“三关速战 / 五关完整挑战”旁增加展示模式分段控制：

- `互动调查`：默认值；玩家主动推进三名侦探的调查。
- `自动演示`：沿用现有 `700ms` 回放和“跳过回放”。

模式只能在进入挑战前选择。挑战进行中不允许切换，避免已查看状态、回放计时和答题状态发生歧义。

### 3.2 互动调查

后端检测请求完成后，互动模式进入以下固定顺序：

1. **语义侦探**解锁。点击后移动到中央证据台并展示语义结果。
2. 语义侦探完成汇报并返回队列，标记“已汇报”；**曲线侦探**解锁。
3. 点击曲线侦探后展示 CPD 结果和曲线，完成后**小队队长**解锁。
4. 点击小队队长后展示前两路证据的确定性关系总结，不展示最终处置动作。
5. 队长完成总结后，答题区解锁，玩家选择证据关系、处置动作和适用时的 Token 起点。

已经汇报的角色可以重新点击回看。回看只切换证据台内容，不改变已完成步骤，不重新播放完整走路动画，也不会锁回后续角色。尚未解锁的角色保持可见，但不可操作，并给出等待原因。

### 3.3 自动演示

自动模式保持当前行为：

- 已返回的五个检测阶段按固定 `700ms` 间隔回放；
- 当前阶段驱动相应公仔的 `approach`、`inspect` 或 `conclude` 动作；
- 玩家可随时点击“跳过回放”进入答题；
- 页面继续说明这是已返回结果的界面回放，不代表模型实时推理。

## 4. 界面设计

### 4.1 中央证据台

采用单一中央证据台，而不是在三名角色头顶同时显示气泡。当前角色移动到中央，固定位置的结果面板更新内容；其余角色留在队列中显示“已汇报”“下一位”或“等待总结”。

该布局的目的：

- 维持明确的语义侦探 -> 曲线侦探 -> 队长顺序；
- 避免三个气泡在手机端拥挤和遮挡；
- 保持证据阅读位置稳定，减少页面跳动；
- 让公仔移动服务于调查流程，而不是纯装饰。

### 4.2 角色状态

每个角色存在以下交互状态：

- `locked`：尚未解锁；可见但禁用；
- `ready`：当前应点击的角色；具有清晰焦点和轻量提示；
- `presenting`：位于证据台并展示结果；
- `visited`：已汇报，可再次点击回看；
- `idle`：自动模式或非当前状态；
- `celebrate`：完成全部挑战后的单次庆祝。

角色必须使用真正的按钮语义，而不是只给 `figure` 绑定点击事件。按钮需要可见焦点、可读名称、`aria-pressed` 或等价选中状态，以及明确的禁用原因。

## 5. 数据与内容

所有汇报均基于完整后端响应已经返回的字段。界面不得把动画描述成实时模型推理，也不得生成接口中不存在的内部思维过程。

### 5.1 语义侦探

展示：

- `semantic_severity`；
- `semantic_categories`；
- `semantic_latency_ms`；
- 语义模型与版本的简短标识（空间允许时）。

证据不可用时显示“语义证据不可用”，仍允许完成该步骤。

### 5.2 曲线侦探

展示：

- `detector_status`；
- `detector_score`；
- CPD 阈值 `h`；
- `suspicious_span.token_start`；
- 现有 `signals` 曲线。

结果面板必须明确写出：分布异常只代表候选信号，不单独证明恶意。无起点或信号不足时显示“不适用”，仍允许继续。

### 5.3 小队队长

队长从语义严重度和 CPD 状态确定性派生证据关系：

- 双路正常；
- 仅语义风险；
- 仅分布异常；
- 双路风险；
- 证据不可用。

队长可以说明证据一致或分歧，并引用前两名侦探已经展示的字段，但在玩家提交前不得展示 `decision`、建议动作或正确答案。

### 5.4 内容可见性

按场景类型分级：

- 合成无害样本：可显示完整 Prompt 和 Token 文本；
- 受保护攻击样本：只显示样本 ID、攻击族、Token 序号、曲线和异常起点，不显示原始攻击 Prompt、suffix 或可重构载荷的 Token 文本；
- 当前挑战页不包含用户自定义输入；若后续接入，可向输入者显示其原文和 Token 文本，但知识智能体仍只接收既定脱敏字段；
- 页面展示结构化证据链和真实工具结果，不伪造模型私有思维链。

## 6. 组件与状态所有权

`ChallengePage` 继续拥有挑战会话、请求、重试、回放计时和答题状态，并新增：

```text
presentationMode: interactive | auto
investigationStep: semantic | cpd | captain | complete
selectedRole: guard | cpd | agent | null
visitedRoles: Set<guard | cpd | agent>
```

建议边界：

- `ChallengePage`：管理模式、解锁顺序、重置规则和答题区是否可见；
- `MascotTeam`：接收每个角色的交互状态，发出角色选择事件，渲染移动状态；
- `InvestigationDesk`：根据选中角色和 `LabRunResult` 展示固定证据内容；
- 现有 `ChallengeSignalPicker`：继续承担曲线与 Token 起点选择，不重复实现图表。

不得把调查步骤藏在 `MascotTeam` 的组件内部状态中，否则重试、下一关、退出和模式选择无法由页面统一复位。

## 7. 重置与异常处理

- 后端请求未返回时，三名角色保持静态，不展示阶段结果；
- 请求失败时沿用“本关调查失败 / 重试本关”，不解锁角色；
- 单项证据不可用时，对应角色汇报固定不可用状态，流程仍可继续；
- 重试本关时清空 `selectedRole`、`visitedRoles` 和调查步骤；
- 下一关时从语义侦探重新开始；
- 退出挑战时清除本次挑战全部互动状态；
- 自动模式跳过回放时直接进入现有答题区，不创建互动模式的已查看记录。

## 8. 动画与响应式

- `ready` 角色只使用低幅提示，不持续闪烁；
- 首次点击当前角色时执行一次走向证据台的动作；
- 回看已完成角色时只切换选中状态和证据内容，不重播完整走路；
- 三名角色始终占据稳定空间，移动不得覆盖证据台、题目或答题按钮；
- 手机端证据台位于公仔队列下方，避免横向溢出；
- `prefers-reduced-motion: reduce` 下取消入场、走位、倾斜、呼吸和庆祝，但点击、选中、汇报和流程推进完整可用。

## 9. 测试与验收

### 9.1 单元与组件测试

- 默认模式是互动调查；
- 自动模式仍按 `700ms` 推进且可跳过；
- 互动模式严格按 guard -> cpd -> agent 解锁；
- 锁定角色不可推进流程；
- 已访问角色可以回看且不改变进度；
- 队长完成前答题区不可见，完成后可见；
- 队长汇报不包含最终 `decision`；
- 重试、下一关和退出正确清空互动状态；
- 不可用证据不会阻断流程。

### 9.2 浏览器验收

桌面和手机分别验证：

- 两种模式只能在挑战开始前选择；
- 三名公仔均可通过鼠标和键盘操作；
- 当前角色移动到证据台且内容对应真实返回字段；
- 结果面板和答题区无重叠、无全局横向滚动；
- 回看角色不重复完整动画；
- 减少动态效果下无 transform 或动画，但流程可完成；
- `/analyze` 和 `/lab` 未发生行为回归。

## 10. 与终极任务的关系

本轮提供的是结构化证据协同的可视化入口，只能支持终极任务演示的前半段。它不宣称已经具备 SuperAgent 的自主闭环。

后续独立阶段应在队长之后增加：

```text
多源安全数据
-> 自主计划
-> 安全工具调用
-> 执行观察
-> 失败反馈
-> 重新规划
-> 处置闭环
```

该阶段需要单独确定工具权限、真实执行与 dry-run 边界、失败注入、审计记录和 ReAct 展示规则，不应与本轮前端互动改造绑定交付。
