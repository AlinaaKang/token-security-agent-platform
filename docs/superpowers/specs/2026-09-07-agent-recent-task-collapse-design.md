# 最近安全任务折叠设计

## 目标

当 Prompt 或 PCAP 历史任务较多时，用户可以收起对应的最近任务列表，降低侧栏拥挤度，同时不影响新建任务和进入调查工作区。

## 交互

- `Prompt 最近任务` 和 `PCAP 最近任务` 各自拥有独立的折叠按钮。
- 分组默认展开，按钮同时显示分组名称、任务数量和方向箭头。
- 收起后仅隐藏该分组的历史任务列表；调查入口和“新建对话”始终可见。
- 折叠状态保存在浏览器本地，刷新后恢复；存储不可用时退化为默认展开。
- 按钮提供 `aria-expanded` 和明确的可访问名称，可用鼠标、触摸和键盘操作。

## 边界

- 不删除、不重新排序、不截断任务数据。
- Prompt 与 PCAP 折叠状态互不影响。
- 每类仍沿用现有最多展示 8 条最近任务的限制。
- 不改变任务状态、路由、后台执行或检查器逻辑。

## 验证

- 组件测试覆盖默认展开、独立折叠和刷新恢复。
- 全量前端测试与生产构建通过。
- 桌面和窄屏检查按钮、任务数量、长标题和折叠后的布局。
