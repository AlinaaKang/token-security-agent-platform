# 统一安全对话与场景化引导设计

## 目标

将 Prompt 与 PCAP 调查统一为可持续交流的安全对话，而不是只能执行一次检测的表单。智能体支持普通问候、能力说明、安全知识问答、任务规划、工具调用和围绕当前证据继续追问，同时明确区分真实数据调查、攻防实验和侦探挑战。修复安全对话及智能体资源页“本页引导”没有内容的问题，并统一对话与最近任务的视觉层级。

## 统一对话能力

- Prompt 与 PCAP 都使用多轮对话模型，历史消息按时间连续呈现，刷新和重新打开后仍可继续。
- “你好”“你叫什么”“你能做什么”等日常交流直接回复，不要求启动检测或授权。
- 安全知识、攻击原理、术语解释和使用帮助直接回答，并明确知识来源范围。
- 用户要求检测 Prompt、上传 PCAP、运行工具或生成报告时，智能体公开任务计划并仅在需要时请求授权。
- 用户可以围绕已有结果继续追问原因、证据、攻击目的、处置建议和报告内容；回答必须受当前案件证据约束。
- 与安全无关的简单交流可以正常响应；复杂的非安全任务会说明专业边界并引导回安全场景。

## 信息架构

- `PCAP 数据调查`处理用户上传的真实 PCAP。智能体负责解析、定位异常 Packet、判断攻击目的、解释证据并生成报告。
- `PCAP 侦探挑战`使用内置脱敏样本和预设关卡。用户主动查看线索、标记异常 Packet、选择攻击类型和目的，提交后获得评分和答案解析。
- `PCAP 检测小队`只属于侦探挑战，不出现在 PCAP 数据调查对话中。
- `PCAP 攻防实验`运行可控案例并展示攻击与防护结果，不承担真实文件调查或挑战评分。

## PCAP 连续对话

1. 用户选择 PCAP 并输入调查目标。
2. 完成上传授权后，页面立即建立一条用户消息，保留原始问题、文件显示名和发送时间。
3. 检测进度与最终结果以智能体消息形式进入对话流，而不是替换整个对话区。
4. 结果消息包含结论、检测统计、局部证据和 Packet 时间轴，但不包含检测小队。
5. 检测完成后输入框持续可用。后续问题引用当前任务的 PCAP 证据回答；证据不足时明确说明边界。
6. 刷新或重新打开历史任务后恢复消息、时间和可公开的结构化结果。

## 对话布局

- 用户消息右对齐，用户头像在右侧，使用浅蓝色消息气泡。
- 智能体消息左对齐，智能体头像在左侧，使用白色或极浅灰背景。
- 消息具有稳定的最大宽度、自动换行和清晰的名称与时间。
- Prompt 与 PCAP 使用相同的对话方向规则。
- Prompt 检测计划和结果同样作为智能体消息进入对话；计划完成后继续保留输入框，不跳转到独立静态结果页。

## 最近任务

- `Prompt 最近任务`与 `PCAP 最近任务`标题增大、加重并左对齐。
- 数量与折叠箭头保留在标题行右侧。
- 任务名称与状态左对齐，增加字号和纵向间距；选中项继续使用浅蓝背景。
- 新任务标题根据首条用户问题生成简短摘要；PCAP 任务优先包含上传文件名或调查目标，避免列表中重复出现通用类型名称。
- 每条最近任务提供删除菜单。确认删除后，同时删除服务端任务记录及该任务在浏览器保存的原始消息；若删除当前任务，则返回相同模式的新对话页。

## 直接结论与检查器

- 计划结束后必须追加一条智能体最终回复，直接说明是否发现风险、关键依据、处置建议及证据边界，不能只停留在“计划 4/4”。
- 最终回复中的事实引用当前任务的公开证据；工具没有返回证据时，明确显示“无法形成可验证结论”。
- 右侧 Prompt/PCAP 调查检查器的标题、页签、空状态、字段标签和正文统一增大一级字号，同时保持紧凑的信息密度和移动端适配。
- 调查报告标题由对应任务的可辨识标题和生成时间组成；PCAP 报告优先包含文件名，Prompt 报告优先包含首条问题摘要，避免报告列表重复显示相同通用名称。

## 场景化本页引导

引导根据路径和查询参数选择独立身份，避免不同页面共用错误的完成状态：

- Prompt 对话：调查类型、快捷入口或历史消息、输入框、案件检查器。
- PCAP 对话：上传与目标、对话进度、证据结果、继续追问、案件检查器。
- 安全知识库：资源用途、知识条目与真实性信息、返回对话入口。
- 数据连接器：连接状态、数据边界与返回对话入口。
- 调查报告：报告列表、生成来源与返回对话入口。

引导只解释和聚焦页面，不发送消息、不上传文件、不执行检测。启动器继续支持拖动、键盘移动、位置保存和重复打开。

## 状态与错误

- 上传、检测或追问失败时保留已有对话和结果，并在对话附近提供可理解的错误信息与重试动作。
- 运行中的 PCAP 任务允许取消；取消后仍保留已获得的公开证据。
- 无证据、解析失败与未发现异常采用不同文案，避免把工具失败解释成安全结论。

## 验收标准

- Prompt 用户消息位于右侧，智能体消息位于左侧。
- PCAP 上传后产生连续对话，检测结束后可继续追问。
- PCAP 数据调查页不再显示“检测小队”。
- PCAP 侦探挑战具有内置关卡式互动，不要求上传用户文件。
- 最近任务标题和任务内容字号增大且左对齐。
- 最近任务名称能够反映首条问题或 PCAP 文件名，并可在确认后单条删除。
- 任务计划完成后，对话中显示可直接阅读的最终结论。
- 右侧案件检查器文字清晰增大，且内容不溢出。
- 同类调查生成的多份报告可以通过任务摘要、文件名和生成时间区分。
- 安全对话及三个智能体资源页的“本页引导”均能显示非空内容并聚焦真实元素。
- 引导导航不会触发上传、消息发送或检测 API。
- 桌面与移动视口中消息、输入框、引导和侧栏不遮挡、不溢出。

## 测试策略

- 先添加失败测试覆盖普通问答、Prompt/PCAP 多轮对话、对话方向、PCAP 结果嵌入、追问保留、检测小队移除和查询参数感知的引导解析。
- 为每个引导目标验证初始页面中存在对应元素，并验证浏览引导不会触发执行动作。
- 运行前端完整测试与生产构建。
- 在 Prompt、PCAP、知识库、连接器和报告页面进行桌面及移动视觉检查。
