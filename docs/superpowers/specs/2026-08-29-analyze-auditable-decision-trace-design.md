# 安全分析页可审计决策轨迹设计

## 目标

在 `/analyze` 的检测结果中增加紧凑的六阶段“可审计决策轨迹”，让评委直观看到系统如何组合语义安全、Token 观测、CPD 与固定融合证据，同时明确它不是模型隐藏思维链。

## 范围与边界

- 只消费现有分析接口已经返回的结构化结果，不新增后端接口、模型调用、SSE、WebSocket、数据库或遥测。
- 不改变语义等级、CPD 分数、异常起点、融合原因、风险分数或处置动作。
- 不显示原始 Prompt、攻击 suffix、Token 文本、词表 Token ID、原始模型输出、私有路径、检索词或隐藏 CoT。
- 固定显示“结构化决策轨迹，不包含隐藏思维链”；界面播放间隔不表示模型耗时。
- 不改变 `/lab`、`/challenge` 和 `/super-agent` 的行为。

## 交互与布局

轨迹位于风险摘要与详细结果之间，保持分析页现有安静、工作台式视觉。六个阶段按真实处理顺序排列：

1. 脱敏接收
2. 语义检测
3. Token 观测
4. CPD 判断
5. 证据融合
6. 处置决策

首次收到新的分析结果后，阶段按固定界面间隔逐项出现。当前阶段显示对应公开证据，已出现阶段可点击回看；回看只切换展示内容，不重新请求、不重新检测，也不改变处置结果。桌面使用横向流程，移动端改为纵向流程，避免横向滚动。

`prefers-reduced-motion: reduce` 下立即显示全部阶段并取消进入动画。键盘用户可以依次聚焦每个已出现阶段，选中状态使用 `aria-pressed` 表达。

## 组件与数据流

新增一个纯映射模块，将现有分析结果转换为六个公开轨迹事件。每个事件只包含稳定 ID、标题、状态、摘要和有限证据字段。映射模块负责标签与缺失值，不读取或拼接受保护原文。

新增紧凑的 `AnalyzeDecisionTrace` 组件，负责：

- 按顺序播放已生成事件；
- 展示当前事件的公开摘要；
- 支持已出现事件回看；
- 清理结果替换和卸载时的计时器；
- 在减少动态效果模式下立即完整展示。

`AnalyzePage` 在成功结果存在时生成事件并渲染组件。输入变化但尚未产生新结果时沿用现有页面状态，不提前展示虚构阶段。

## 阶段证据

- 脱敏接收：仅说明请求已进入检测链路，不回显 Prompt。
- 语义检测：公开语义等级、规范化风险类别和可用时的耗时。
- Token 观测：公开观测数量与完成状态，不显示 Token 文本或词表 ID。
- CPD 判断：公开是否存在分布异常候选、检测分数、阈值和异常起点。
- 证据融合：公开语义与 CPD 的关系以及固定融合原因的中文标签。
- 处置决策：公开最终动作与风险分数，并说明动作来自固定策略融合。

任何字段不可用时显示“不可用”或“不适用”，不得根据缺失信息补写推理。

## 失败与替换

- 分析失败时不渲染新轨迹，继续使用现有错误处理。
- 新结果替换旧结果时，从第一阶段重新播放并清除旧计时器。
- 组件卸载时清除全部计时器，避免写入已离开的页面。
- 空信号、无 CPD 起点或语义证据不可用时仍生成有界事件，不阻断页面。

## 验证

- 纯映射测试锁定六阶段顺序、公开标签、缺失值和隐私禁止字段。
- 组件测试覆盖逐项播放、点击回看、结果替换、计时器清理和减少动态效果。
- 页面测试确认轨迹只在成功结果后出现，不新增请求，不改变现有风险与处置结果。
- 全量前端测试和生产构建必须通过。
- Playwright 在 `1440x900` 与 `390x844` 验证无溢出、键盘可回看、减少动态效果和零控制台错误。
