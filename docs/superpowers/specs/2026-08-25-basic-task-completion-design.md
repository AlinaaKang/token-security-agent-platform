# 基础任务收口设计

## 目标

将当前已经验证的 Entropy-CPD 研究基线收口为一个可运行、可审计、可评测、可演示的场景化安全智能体，满足赛题基础任务“解决单一特定安全痛点”的要求。

单一痛点保持不变：大模型应用入口缺少对优化型 jailbreak 后缀的 Token 级异常检测和起点定位能力。系统负责发现并定位“分布异常候选”，不把 CPD 告警包装成已经完成语义确认的 jailbreak 判定。

## 完成边界

基础任务完成时必须具备：

1. Prompt 在线分析、Token 观测、CPD 检测、异常定位和实验处置链路。
2. 使用冻结数据划分生成的真实评测结果，而不是页面占位数据。
3. 至少两种非 CPD 基线与 Entropy-CPD 的同数据、同划分比较。
4. 不保存 Prompt 原文的安全事件审计。
5. 可按样本 ID 演示真实冻结测试样本，同时隐藏攻击原文和 Token 文本。
6. 页面明确区分“Token 分布异常候选”与“已确认 jailbreak”。
7. 与实现一致的设计、开发、测试和实验说明。

以下内容不进入本阶段：语义复核、RAG、安全知识库、NLL/Entropy 融合决策、ReAct、多工具闭环、PCAP、BEAST 和 AutoDAN-HGA 生成。它们属于进阶或挑战任务，不能阻塞基础任务交付。

## 系统结构

```text
Web 安全分析
  -> FastAPI 分析接口
  -> Qwen Token 观测
  -> Entropy-CPD 检测与定位
  -> 模式感知策略
  -> 脱敏事件存储

冻结评测数据
  -> Global NLL / Window NLL / Entropy-CPD
  -> 相同 calibration/dev/test 划分
  -> 隐私安全聚合报告
  -> 评测中心 API 与页面

受保护原始数据目录
  -> 样本 ID 解析
  -> 服务端分析
  -> 仅返回脱敏 Token 序号和统计量
```

模块保持单一职责：检测工作流不读取评测报告，评测服务不加载攻击原文，事件存储不保存 Token 文本，真实样本目录只在显式配置后启用。

## 基线评测

所有方法必须使用现有的 group-aware calibration/dev/test 冻结划分，禁止使用测试标签调参。

### Global NLL

Prompt 分数为用户 Token 的平均 NLL。阈值在 calibration 选择，在 development 冻结，test 只评估。该方法表示整句困惑度类检测器。

### Window NLL

使用固定窗口计算局部平均 NLL，Prompt 分数为所有窗口中的最大值。窗口长度候选只能在 calibration/dev 选择。该名称用于项目内部，不在未复现论文精确定义前声称为论文 WPP。

### Entropy-CPD

保持当前固定 system Prompt 熵基线、Page-CUSUM、`k`/`h` 冻结流程不变。

统一报告总体 Precision、Recall、F1、AUROC、benign FPR、逐攻击族 Recall 和推理延迟。只有 Entropy-CPD 报告后缀起点定位指标，因为其他基线不产生变化点。

评测中心必须同时展示 F1-selected 与开发集选择的低 FPR 工作点。字段名使用 `low_fpr_selected_on_dev`，避免暗示测试集一定达到 10% FPR。

## 判定与处置语义

API 新增显式检测状态：

- `no_token_anomaly`：CPD 分数低于 `h`。
- `token_anomaly_candidate`：CPD 分数达到或超过 `h`。
- `semantic_verification` 固定为 `not_performed`，直到进阶任务真正实现。

分析模式允许展示“实验拦截”，用于复现实验阈值效果；在线防护模式在没有语义复核时不得把 CPD 单证据直接标成确认 jailbreak，动作降为人工复核。页面使用“Token 异常候选”“未进行语义确认”等文本，不使用“已确认攻击”。

低于 `h` 的 Prompt 不能因为风险归一化或策略阈值被标记为 CPD 告警或拦截。

## 安全事件审计

使用 SQLite 持久化事件，数据库位于未跟踪的运行目录。每条事件只保存：

- request ID、UTC 时间；
- Prompt SHA-256、字符数和 Token 数；
- CPD 分数、`k`、`h`、异常起点；
- 检测状态、处置动作、工作模式；
- 模型、校准版本和延迟。

禁止保存 Prompt、suffix、Token ID 对应文本、模型回答和请求头。事件 API 支持分页和按处置/状态筛选，默认返回最近事件。

事件写入失败不能伪装成分析成功且已审计。分析响应增加审计状态；服务可继续返回检测结果，但明确标记 `audit_persisted=false`，并记录不含请求正文的服务错误。

## 真实样本演示

真实样本功能默认关闭，仅当 AutoDL 显式配置 CPDonline 原始目录和安全样本目录时启用。

目录 API 仅返回样本 ID、攻击族、数据划分和是否已评测。执行 API 通过样本 ID 在服务端读取 Prompt，调用同一分析工作流，但响应必须：

- 不返回 Prompt 和 suffix；
- 将 Token 文本替换为空字符串或固定占位符；
- 返回 Token 序号、Entropy、NLL、CPD、风险和异常起点；
- 记录数据集 commit、样本 ID、模型和校准版本；
- 不写入普通用户事件库，或使用样本 ID 哈希明确标记为演示事件。

不存在、非测试集或未在安全目录中的样本 ID 必须拒绝，不能允许任意路径或任意 CSV 行访问。

## API 与前端

新增只读接口：

- `GET /api/v1/evaluation/summary`
- `GET /api/v1/events`
- `GET /api/v1/demo-samples`
- `POST /api/v1/demo-samples/{sample_id}/analyze`

评测报告路径、事件数据库路径和演示目录通过环境变量配置。未配置时对应接口返回明确的不可用状态，主分析接口仍可使用。

前端三个页面全部成为真实功能：

- 安全分析：显示检测状态、语义确认状态、模式感知动作和校准来源。
- 安全事件：分页展示脱敏事件，不出现 Prompt 摘要或 Token 文本。
- 评测中心：展示冻结测试规模、三种方法、双工作点、逐攻击族召回和未评测攻击族。

真实样本演示作为安全分析页的样本选择器，不把攻击原文填入文本框。

## 错误处理

- 评测报告校准版本与在线检测器不一致时，评测中心标记为历史报告，不能显示为当前线上结果。
- 报告包含 Prompt、suffix 或 Token 文本字段时拒绝加载。
- SQLite 初始化失败时健康检查标记审计降级，但模型检测状态独立报告。
- 演示目录 checksum 或 CPDonline commit 不匹配时禁用真实样本演示。
- 基线评测遇到单一样本失败时只输出 sample ID 和错误类型，停止冻结测试，不跳过样本美化结果。

## 测试与验收

所有行为修改遵循测试先行。

### 自动测试

- 单元测试：三种分数、阈值选择、报告隐私校验、事件脱敏、分页过滤、判定语义。
- 集成测试：分析后产生脱敏事件；评测报告加载；真实样本响应不含原文；未配置功能正确降级。
- 前端测试：三个页面加载真实 API 数据；异常候选不显示为已确认 jailbreak；错误与空状态可见。

### AutoDL 验收

- 三种方法在相同冻结 test split 上生成聚合报告。
- 在线 Entropy-CPD 与离线结果逐项一致。
- 真实 AutoDAN、AdvPrompter、GCG 样本各完成至少三次 ID 演示。
- 无害 JSON、代码、多语言和普通问答再次复测并公开误报。
- API、事件数据库和评测报告均扫描确认无 Prompt、suffix、Token 文本泄漏。

### 基础任务完成门槛

1. 后端、前端、构建和 AutoDL 验收全部通过。
2. Web 三个页面都使用真实后端数据，不保留“测试集未载入”等占位状态。
3. 报告明确公开当前 FPR，不使用测试集重新调参。
4. 真实样本演示可复现且不暴露原文。
5. README 和实验文档与当前部署状态一致。
6. BEAST、AutoDAN-HGA 保持 `not_evaluated`，不虚报覆盖范围。

## 创新表述边界

基础任务可以表述为：将固定系统 Prompt 熵基线的在线变化点检测用于大模型入口，提供优化型后缀的 Token 级异常定位、冻结评测、可审计智能体处置和隐私安全演示。

不得表述为：发明 CPD、准确识别所有 jailbreak、实现低误报生产防火墙、已经完成语义验证或已经覆盖未评测攻击族。
