# 安全智能体 PCAP 上传与专用检查器设计

## 目标

修复安全智能体输入框只能选择 PCAP 文件名、不能上传文件内容的问题，并让右侧案件检查器根据 Prompt、PCAP 和跨域任务展示不同的调查结构。

## PCAP 数据流

1. 用户通过输入框左下角的 `+` 选择一个 `.pcap` 或 `.pcapng` 文件。
2. 输入框上方显示文件名、格式与大小；此时文件仍在浏览器本地。
3. 用户发送任务后看到专用确认界面，明确说明文件只进入本机隔离区，不上传 AutoDL。
4. 用户确认后依次调用现有 `pcapUploadCapability`、`authorizePcapUpload` 和 `uploadPcapForDetection`。
5. 本机 PCAP 服务校验格式与大小，并仅在无网络、只读根文件系统、非 root、资源受限 Docker 中解析。
6. 工作台轮询现有 PCAP mission，中央区连续显示上传进度、运行状态、已检测样本、异常候选、packet 范围、目的候选、失败与未覆盖范围。
7. 只有显式取消按钮可取消 mission；切换检查器标签不得终止检测。

文件名仅用于当前浏览器的选择摘要，不进入 AutoDL、服务器安全智能体 SQLite、事件或报告。PCAP payload、地址、端口和原始请求保持不公开。

## 任务边界

浏览器上传 PCAP 使用本机 mission，不再创建需要远端 `pcap:read` 的 `pcap_dataset_investigation`，因为远端进程不能读取浏览器本地文件。没有选择文件时，普通自然语言 PCAP 数据集任务继续保留现有目录型批量调查能力。

## 专用检查器

### Prompt 安全调查

标题为“Prompt 调查检查器”，标签固定为：

- Guard：语义判定与类别证据；
- Token：Token/CPD 异常、定位与阈值来源；
- 复核：反事实复核与证据冲突；
- 工具：真实调用状态和公开错误；
- 报告：结论、引用与限制。

### PCAP 调查

标题为“PCAP 调查检查器”，标签固定为：

- 概况：mission 状态、成功数、失败数与证据数；
- Packet：异常候选、packet 范围、置信度和目的候选；
- 解析：Docker 检测事件、失败代码和未覆盖范围；
- 报告：证据 ID、建议动作和未知项。

目录型 PCAP 智能体任务也使用 PCAP 检查器；没有真实 mission 结果时明确显示“尚未取得可验证 PCAP 结果”，不能把工具失败呈现成未命中。

### 跨域与知识任务

跨域任务继续使用通用的证据、假设、工具、时间线和报告检查器。纯知识问答显示知识来源与回答范围，不伪造检测步骤。

## 状态颜色

- 红色只表示检测到异常候选；
- 绿色表示成功执行或当前范围未命中；
- 琥珀色表示失败、降级、等待授权或需要复核；
- 蓝色表示身份、导航、运行中和结构化审查链。

所有状态同时显示文字，不只依赖颜色。

## 错误处理

- 文件扩展名、空文件和大小在浏览器侧先校验；服务端仍执行魔数和长度校验。
- PCAP API 或 Docker 不可用时保留文件选择并提示如何恢复。
- 上传授权过期或已使用时允许重新确认，不复用旧授权。
- 解析失败显示具体公开失败类别，结论为“不完整”，不显示“安全”。
- 轮询暂时失败后有界重试，已取得的公开结果不清空。

## 测试

- 文件选择不会立即上传，发送后必须再次确认。
- 确认后真实调用本机上传授权和上传接口，且不调用远端 `createAgentTask`。
- 上传、轮询、取消、格式错误、服务不可用和失败样本分别有回归测试。
- Prompt、PCAP、跨域任务渲染不同检查器标题和标签。
- 检查器切换不调用取消接口。
- PCAP 文件名、payload、地址和端口不进入远端 API 请求、事件与报告。
- 完整前端测试、生产构建和 PCAP 后端隐私回归通过。
