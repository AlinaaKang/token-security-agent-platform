# 最近安全任务侧栏设计

## 目标

将安全智能体页面顶部的横向任务条移入左侧导航，使案件恢复方式接近 Codex 的任务列表，同时保持当前单一安全工作台的信息架构。此次不增加没有真实数据边界的“项目”层级。

## 信息架构

- “安全案件”分组继续保留“安全智能体”和“安全事件”两个主入口。
- 仅在“安全智能体”入口下方显示“最近安全任务”子列表。
- 子列表最多直接显示 8 个任务，按更新时间倒序排列。
- 顶部横向任务条删除，主区域只保留案件标题、对话、计划、进度、限制和输入框。
- 没有历史任务时不渲染空列表，避免增加无效界面。

## 任务项

每项显示任务标题和一个文字状态，当前任务使用浅蓝背景与 `aria-current` 标识。状态映射固定为：

- `awaiting_authorization`：等待授权
- `planned`、`queued`：准备执行
- `running`：运行中
- `paused`：已暂停
- `completed` + `risk_found`：发现风险
- `completed` + `safe`：当前未命中
- `completed` + `contained`：已处置
- `completed` + `inconclusive`：结论不确定
- `degraded`：检测未完整
- `failed`：执行失败
- `cancelled`：已取消

红色只用于“发现风险”，绿色只用于“当前未命中/已处置”，琥珀色用于等待、失败、降级或不确定；其他运行状态使用主蓝色。状态始终有文字，不只依赖颜色。

## 导航与数据流

- 任务列表使用现有 `GET /api/v1/agent/tasks`，不增加新的后端列表接口。
- 点击任务导航到 `/super-agent?task=<task_id>`。
- `AgentWorkspacePage` 读取 `task` 查询参数，调用现有任务接口恢复案件，并同步当前高亮。
- 新建任务和任务状态更新后刷新侧栏列表；使用一个由应用壳管理的轻量刷新信号，避免侧栏和页面各自维护不一致的历史副本。
- 移动端点击任务后自动关闭导航抽屉，桌面端保持侧栏可见。
- 无效或已删除的任务 ID 显示可恢复错误，用户可新建任务，不回退到其他案件。

## Prompt 显示与隐私边界

- 用户原话发送后立即作为用户消息气泡显示。
- 原始 Prompt 按任务 ID 保存在当前浏览器的本地对话记录中，因此刷新页面或重新打开历史任务后仍可恢复。
- 本地记录不上传 AutoDL，不进入服务器 SQLite、检测事件、调查报告或公开 API；后端继续只保存脱敏占位符。
- 界面明确标注“原文仅保存在此浏览器”，并提供“清除本地对话”操作。
- 清除操作只删除浏览器中的原文，不删除后端的脱敏任务、证据或报告。
- 本地记录最多保留最近 20 个任务，并与现有任务列表上限一致；超过上限时删除最旧的本地对话。
- 在共享电脑上，本地记录可能被同一浏览器配置的其他使用者看到，使用者应在演示后执行清除。

## 消息时间

- 每条用户和智能体消息都在角色名称右侧显示本地时间。
- 当天消息显示 `HH:mm`，昨天显示 `昨天 HH:mm`，同年更早的消息显示 `M月D日 HH:mm`，跨年消息显示 `YYYY年M月D日 HH:mm`。
- 使用语义化 `<time datetime="...">`，悬停标题显示完整本地日期和时间。
- 时间使用次要文字色，不与角色名称或检测状态竞争视觉层级；窄屏允许换行但不能遮挡消息内容。
- 浏览器本地恢复的用户消息保留首次发送时间，不在刷新后改写。

## 测试

- 侧栏渲染最近任务、准确状态和当前高亮。
- 点击任务更新查询参数并恢复对应案件。
- 新建任务后列表出现新项目。
- 移动端任务点击关闭导航。
- 顶部横向任务条不再存在。
- 刷新和重新打开历史任务后仍能恢复浏览器本地 Prompt。
- “清除本地对话”后不再显示原文，但后端脱敏任务仍可打开。
- 用户和智能体消息显示正确的本地时间，跨日和跨年格式可预测。
- Prompt 原文不进入后端任务响应、服务器 SQLite、事件或报告。
- 前端完整测试、生产构建和后端相关回归通过。
