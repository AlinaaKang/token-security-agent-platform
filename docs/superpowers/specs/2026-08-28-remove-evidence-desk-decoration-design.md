# 移除中央证据桌装饰设计

## 目的

挑战页三名侦探之间的圆形 `ScanSearch` 图标没有点击行为，也不承载调查状态，但视觉上容易被理解为查询按钮。移除该装饰，减少错误操作预期。

## 范围

- 从 `MascotTeam` 删除 `ScanSearch` 导入和 `challenge-evidence-desk` 装饰节点。
- 删除仅服务于该节点的桌面端和移动端 CSS。
- 保留三名侦探、公仔状态图标、移动动画、互动顺序和下方真实证据面板。
- 不修改后端、API、样本、评分、调查状态或其他页面。

## 行为与布局

删除后，三名侦探之间使用现有阵列布局自然留白。Guard、CPD 和 Captain 的移动目标与状态仍由现有调查状态控制；中央装饰从未参与定位计算，因此不需要调整数据流或事件处理。

## 错误与兼容性

该元素是 `aria-hidden` 的纯装饰，删除不会改变可访问名称或键盘交互。移动端对应宽度规则一并删除，避免残留无效样式。减少动态效果规则保持不变。

## 验收

- 组件测试证明不再渲染中央证据桌装饰。
- 既有 `MascotTeam` 与 `ChallengePage` 测试全部通过。
- 完整前端测试和生产构建通过。
- 在挑战页确认公仔阵列无异常空框、错位或交互回归。
