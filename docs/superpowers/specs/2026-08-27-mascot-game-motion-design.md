# Token 侦探挑战公仔游戏化动效设计

## 目标

让 `/challenge` 中的三名侦探公仔具有清晰但克制的游戏式动作，在不影响基础页面稳定性、答题效率和检测结果真实性的前提下，增强挑战模式的参与感。

动效只回放后端已经返回的检测阶段。它不表示实时推理、隐藏思维过程、并行执行或因果证明。

## 范围

本次只修改挑战模式的前端表现：

- 使用现有的 Guard、CPD 和 Agent Captain 透明 WebP 公仔。
- 根据挑战阶段和返回的 `LabStage.stage_id` 驱动动作。
- 增加固定的中央证据台及角色走近、观察、归队和庆祝动作。
- 保留静态状态作为动画不可用时的自然降级结果。

本次不修改 `/lab` 专业工作流，不修改检测算法、后端接口、AutoDL 模型服务、挑战样本、计分规则或数据存储方式，也不引入动画依赖、Canvas 游戏引擎、遥测或排行榜。

## 动作编排

### 准备阶段

三个侦探依次短暂入场，然后进入低幅度待机状态。待机动作由轻微呼吸、探头或帽子晃动组成；三个角色使用错开的动画时序，避免机械同步。

### 检测结果回放

当前回放阶段只激活一名对应角色：

| 返回阶段 | 活动角色 | 表现 |
| --- | --- | --- |
| `semantic_guard` | Guard 语义侦探 | 向中央证据台移动并停下查看 |
| `token_observation` | CPD 曲线侦探 | 向证据台移动并前倾观察 |
| `entropy_cpd` | CPD 曲线侦探 | 保持观察姿态并强调曲线状态 |
| `fixed_fusion` | Agent 小队队长 | 向中央移动并做确认动作 |
| `knowledge_retrieval` | Agent 小队队长 | 保持中央位置并强调结论状态 |

角色的移动仅发生在公仔场景内部，使用视觉变换实现，不改变文档布局。未激活角色保持低幅度待机状态。

现有每阶段约 350ms 的播放间隔调整为约 700ms，使走近与观察动作可被辨认。用户仍可使用“跳过回放”立即进入答题。

### 答题阶段

回放结束后，三个角色回到各自固定位置。动作降为安静待机，不能吸引超过题目和操作控件的视觉注意力。

### 揭晓与完成阶段

- 普通揭晓：角色保持归队状态，由现有颜色和状态图标表达结果。
- 证据分歧：队长做一次短暂左右查看动作，配合固定的“证据分歧”状态文字。
- 挑战完成：三名角色做一次短促、错峰的小跳或帽子轻点动作，随后停止庆祝动作。

庆祝动作不得循环播放。

## 组件与状态设计

`ChallengePage` 继续负责挑战会话和阶段回放。它向 `MascotTeam` 传入现有 `phase`、`replayStageId` 和 `evidenceConflict`，并增加足够明确的回放状态，使组件能够区分回放、答题、揭晓和完成。

`MascotTeam` 负责：

- 将 `LabStage.stage_id` 映射到活动角色。
- 为场景、角色和图片包装层生成语义明确的状态类或数据属性。
- 始终挂载三名角色，避免切换阶段时图片重新加载或布局变化。
- 渲染一个装饰性的固定证据台，不引入交互控件。

CSS 负责所有位移、倾斜、待机和庆祝动画。固定尺寸、网格轨道和 `overflow: hidden` 继续约束场景边界。桌面端允许较明显的横向移动；移动端缩小移动距离，保持三名角色和标签完整可见。

## 可访问性与降级

- 公仔名称和现有状态文字继续提供可读语义；证据台属于装饰内容并从辅助技术中隐藏。
- 动画不承载唯一信息，所有阶段仍通过文字、颜色和图标表达。
- `prefers-reduced-motion: reduce` 下取消入场、走位、倾斜、呼吸和庆祝，仅保留无动画的激活状态。
- 浏览器不支持动画时，页面自然显示当前静态高亮，不影响答题、跳过回放和计分。
- 动画不自动播放声音，不增加闪烁效果，也不使用快速重复缩放。

## 稳定性约束

- 不改变挑战请求数量、请求内容或后端响应处理。
- 不因动画延迟启用答题控件；回放结束与跳过回放仍由现有状态机决定。
- 动画元素不得覆盖题目、按钮、Token 选择器或结果区域。
- 公仔和场景使用稳定尺寸，动态内容不得导致累计布局偏移或全局横向滚动。
- 动作名称和页面文案统一使用“检测结果回放”，不使用“实时思考”“推理过程”或“智能体脑内过程”等表述。

## 测试与验收

### 组件测试

- 每个返回阶段激活正确角色，并带有对应动作状态。
- 三名公仔在所有阶段始终挂载。
- 答题阶段回到安静待机状态。
- 证据分歧只触发队长分歧动作。
- 完成阶段触发一次庆祝状态。

### 页面测试

- 回放按约 700ms 间隔推进，结束后可以正常答题。
- “跳过回放”立即停止阶段推进并恢复答题流程。
- 动画状态不改变原有计分、重试和下一关行为。

### 浏览器验收

- 在 1440x900 桌面视口和 390x844 移动视口检查公仔、文字和控件无重叠、无裁切、无全局横向溢出。
- 检查回放中的角色走位、答题待机和完成庆祝均可辨认且不阻塞操作。
- 在减少动态效果模式下确认所有位移、倾斜、呼吸和庆祝均被取消。
- 运行前端测试、生产构建和挑战模式关键流程测试，确认基础页面与 `/lab` 不受影响。

## 完成标准

用户能在挑战回放中直观看到三名侦探按职责出场，在答题时不受持续动画干扰，并在挑战完成后获得短暂反馈；与此同时，挑战的检测、计分、隐私边界和基础页面稳定性保持不变。
