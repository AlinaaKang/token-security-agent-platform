# Token 侦探挑战

`/challenge` 是 AI 安全攻防实验舱的游戏化入口。它复用真实的语义 Guard、Entropy-CPD、固定融合、反事实检查和知识证据结果，但不改变 `/lab` 专业调查流程，也不新增后端、模型、数据库或遥测。

## 如何使用

1. 保持 AutoDL API 隧道映射到本机 `127.0.0.1:18000`。
2. 在 `frontend` 目录运行 `npm.cmd run dev -- --host 127.0.0.1 --port 5174 --strictPort`。
3. 打开 `http://127.0.0.1:5174/challenge`。
4. 选择“三关速战”或“五关完整挑战”，点击“进入挑战”。
5. 查看录制回放，也可立即跳过；依据语义等级和三条 Token 信号曲线选择证据关系、处置动作和适用时的 CPD 起点。
6. 提交后查看玩家答案、系统原始动作、逐项得分、反事实敏感性和调查阶段摘要。

刷新页面或点击“退出挑战”会清空本次挑战。进度、答案、分数和连击只存在 React 内存中，不写入 localStorage、sessionStorage、Cookie、IndexedDB 或事件数据库。

## 关卡定义

- 三关速战：普通无害、无害格式突变、AutoDAN。
- 五关完整挑战：普通无害、无害格式突变、GCG、AutoDAN、AdvPrompter。

当前挑战只声明 GCG、AutoDAN 和 AdvPrompter 三类受保护优化攻击，不声明直接危险、BEAST 或 AutoDAN-HGA 挑战覆盖。若完整模式缺少任一攻击族，只禁用五关模式；实验舱或 GPU 不可用时，设置页显示固定降级状态。

## 评分规则

每关按当前系统结果确定性计分：

- 处置动作：50 分。`sanitize_recheck` 在玩家分类中按“人工复核”计分，但揭晓保留系统原始标签。
- 证据关系：20 分。四类为双路正常、仅语义风险、仅分布异常、双路风险。
- Token 起点：30 分。与 CPD 起点距离 0-3 得 30 分，4-8 得 15 分，9 以上或未选择得 0 分。

不存在 CPD 起点时，定位项不适用；语义或 CPD 证据不可用时，证据关系项不适用。每关分数按适用分值归一化到百分制，总分是所有已完成关卡百分制分数的算术平均值。

挑战得分只表示玩家与当前系统输出的一致程度，不是检测准确率、攻击覆盖率、召回率、F1 或 CPD 定位准确率。

## 侦探小队与回放

- Guard 语义侦探：对应语义安全等级和类别。
- CPD 曲线侦探：对应 Token 观测、Entropy/NLL 和变化点候选。
- Agent 小队队长：对应固定融合与知识证据阶段。

接口完成后，页面按返回的 `LabStage` 顺序每 350ms 切换当前角色。这个过程是已完成结果的录制回放，不是实时流式执行、并行推理、思维链或因果证明。页面显示的阶段耗时始终采用服务端 `latency_ms`，不使用 350ms 展示间隔冒充模型耗时。减少动态效果模式会取消角色位移、弹跳和过渡，但保留文字与图标状态。

## 隐私边界

挑战运行固定发送：

```json
{
  "scenario_kind": "frozen",
  "sample_id": "<场景 ID>",
  "mode": "analysis"
}
```

受保护样本不向浏览器返回、渲染、持久化、记录或截图以下字段：`prompt`、`suffix`、`token_text`、`token_id`、`query_text`、`raw_output`、`guard_raw_output`。截图只使用合成无害场景或受保护样本 ID，不包含攻击原文。

## 失败与边界情况

- 本关请求失败：显示固定“本关调查失败”，不显示异常正文，不记录答案或分数，可重试同一关。
- 知识阶段不可用：不阻断基础证据评分，报告使用已有确定性结果。
- 无 CPD 起点：页面显示“定位不适用”，不会强制选择 Token。
- 证据关系不可用：该项不进入适用分值。
- 刷新或退出：清空内存会话，不产生排行榜或历史记录。

## 2-3 分钟演示

1. 在设置页介绍三名侦探和两种关卡组，强调挑战分数不是检测性能。
2. 进入三关速战，展示普通无害请求的录制回放、双路正常、放行和无起点归一化计分。
3. 展示无害格式突变，说明“分布变化不自动等于恶意”，语义证据用于降低误判。
4. 展示 AutoDAN 受保护样本，只说明 sample ID、三条信号、CPD 候选、起点、融合动作和反事实敏感性，不展示原文。
5. 切回设置页指出五关模式增加 GCG 与 AdvPrompter，最后展示隐私边界与真实验收数据。
