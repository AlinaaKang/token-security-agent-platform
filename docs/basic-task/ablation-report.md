# 智能体冻结消融实验报告

报告版本：`agent-ablation-v1`
实验日期：2026-08-26

## 1. 实验目的

本实验在同一批冻结样本和同一组模型观测上比较三条可部署链路：

- `semantic_only`：只使用 Qwen3Guard 语义等级。
- `cpd_only`：只使用 Entropy-CPD Token 变化证据。
- `fusion`：按固定决策表组合语义等级和 CPD 告警。

实验回答两个问题：融合是否确实改善总体分类，以及 CPD 在语义模型之外提供了什么独立价值。所有阈值只使用 calibration/dev；test 只执行一次冻结评估，不根据 test 标签回调参数。

## 6. CPD 定位能力

只有生产档位报告定位，因为 constrained profile 的目标是分类约束，不应继承另一档位的定位结果。CPD 在 423 条带已知后缀边界的 test 样本上产生 410 个起点预测：

- 字符级 onset MAE：38.0049。
- 预测起点落入真实后缀：58.39%。
- eligible/predicted：423/410。

当前实现以字符坐标保存真实 suffix 边界，因此不能把 38.0049 写成 Token MAE。Web 上的 T0/T1 序号用于脱敏展示，不代表真实原文 Token。

## 7. 结论与创新边界

本实验不支持“融合全面优于单路”或“CPD 提升总体 F1”的表述。Semantic-only 在 `fpr_05` 档位达到 F1 97.64%、test FPR 1.24%；Fusion 只把 Recall 从 96.12% 提至 99.61%，同时 F1 降至 96.71%、test FPR 升至 10.25%，并且没有满足 dev 的 5%/10% 约束。生产档位下，Fusion 的高 Recall 也伴随 62.73% FPR。

因此可辩护的创新点是：

> 在强语义安全分类前提下，增加与语义证据分离的 Token 分布变化通道，输出异常起点、证据冲突和模式感知处置；再通过冻结消融诚实判断何时应拦截、何时只应复核。

CPD 当前适合作为定位和复核证据，不适合作为单证据生产封禁器。Qwen3Guard 和 CPDonline 均为第三方能力，本项目原创部分是全链路智能体编排、证据边界、冻结评测、隐私设计和可审计处置，不声称发明这些模型或算法。

## 8. 失败与限制

- 正式收集和 test 评估失败数均为 0，但这不消除统计误差或数据覆盖偏差。
- BEAST、AutoDAN-HGA 没有进入指标，不能声称覆盖五类优化攻击。
- 无害突变仍是主要误报来源，尤其在 production 融合档位。
- 本实验衡量入口检测，不衡量目标大模型生成后的越狱成功率。
- 延迟来自单机 RTX 4090 D 实验，不构成生产 SLA。
- 知识智能体在动作冻结后运行，不能修改这里的分数、动作或指标。
