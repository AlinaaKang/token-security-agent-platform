# 进阶任务实验报告：安全知识检索与引用报告

## 1. 研究问题

1. 固定离线知识快照能否为不同安全证据组合检索到相关官方控制建议？
2. 知识增强是否保持基础检测动作完全不变？
3. 在严格 3 秒生成边界下，系统能否保证引用合法并可靠降级？

## 2. 实验设置

- 快照：`official-v1`，12 张卡，OWASP/MITRE/NIST
- Fixture：36 条安全合成元数据，不含 Prompt 或攻击指令
- 风险域：prompt injection、jailbreak、sensitive information、excessive agency、governance、incident response
- 检索：SQLite FTS5，标签权重 2.0，词法权重 1.0，Top-3
- 报告：Qwen2.5-7B-Instruct，确定性解码，最多 256 Token，最多 3 秒
- 冻结规则：查看测试结果后不调整权重、卡片或 fixture

## 3. 冻结结果

总体 Hit@1 为 0.9444，Hit@3 为 0.9722，MRR 为 0.9583。所有返回引用都属于快照，引用有效率为 1.0；知识开关前后基础动作一致率为 1.0。

按风险域看，prompt injection、sensitive information、excessive agency、governance 和 incident response 的 Hit@3 为 1.0；jailbreak 的 Hit@3 为 0.8333，即 6 条中有 1 条未命中 Top-3。该失败样本没有在测试后用于调权。

## 4. 真实链路结果

6 条受保护融合样本共得到 17 个合法引用，9 个冻结攻击 ID 共得到 27 个合法引用；两组 off/report 基础动作一致率均为 100%，错误为 0。

15 条 report 请求中，1 条在边界内生成严格 JSON，14 条触发确定性模板回退。回退的主要原因是 3 秒生成上限，而不是检索失败：检索 P95 小于 0.4 ms，报告生成 P95 约 3.024 秒。所有回退报告仍只引用本次 Top-3，并明确说明知识证据不改变基础动作。

## 5. 解释

结果支持以下结论：本地知识检索可在低内存、亚毫秒检索开销下为大多数冻结安全元数据提供官方依据；引用校验和后置增强能够保持基础检测动作不变。

结果不支持“LLM 报告通常能在 3 秒内完成”的表述。当前硬件和生成配置下，模型报告大多回退模板，因此现场演示必须把“模板降级”作为正常、安全且可审计的状态，而不能隐藏。

## 6. 与基础创新的关系

基础任务创新是 Token 熵变化点定位、语义 Guard、固定融合和脱敏处置闭环。进阶创新是在该结论之后加入隐私受限的证据智能体：CPD 起点控制查询前缀，官方卡片提供可追溯依据，严格引用与确定性回退保证失败时不篡改安全动作。

## 7. 局限与下一阶段

- 36 条 fixture 是工程检索评测，不是自然分布下的大规模 RAG benchmark。
- 知识卡为项目撰写的官方资料摘要，不等于官方组织对本系统的认证。
- 当前没有独立冻结语义准确率数据集。
- Jailbreak 风险域仍有 1/6 Top-3 未命中。
- 14/15 报告使用模板回退，后续需在独立开发集上评估更小报告模型或更短 schema，不能调测试集。
- 在线知识更新、人工反馈学习和规则自动修改尚未实现；若实施，必须增加签名快照、审批、回滚和独立评测。
