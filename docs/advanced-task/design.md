# 进阶任务系统设计：可追溯研判与平台内部处置

## 1. 目标与边界

基础链路已经给出语义等级、Entropy-CPD 异常候选与固定动作。进阶任务解决的痛点是：在不泄露原始 Prompt、攻击 suffix 和 Token 内容、不允许知识层改写基础动作的前提下，把研判依据、反事实敏感性和可验证处置回执组织成一条可审计智能体链路。

本阶段不做在线爬取、自动改规则、反馈训练或外部防火墙/EDR/SIEM 联动。所有工具只在本平台内部执行。

## 2. 总体链路

```text
Qwen3Guard + Entropy-CPD + 固定融合
  -> 不可变基础 AnalysisResult
  -> SafeQueryBuilder（截断、脱敏、固定路由标签）
  -> official-v2 内存 FTS5 Top-3
  -> 严格引用报告或确定性模板回退
  -> 反事实截断重检（只作敏感性证据）
  -> 工具预览
  -> 用户确认
  -> 平台内部执行、SQLite 回执与可验证证据包
```

知识、反事实和工具层都不能降低或改写基础 `decision`，也不能改写 `detector_score`、`suspicious_span`、语义证据或模型/校准来源。

## 3. 离线知识快照

- 版本：`official-v2`
- 卡片数：18
- 发布方：CAC、MITRE、NIST、OWASP
- 卡片 SHA-256：`2dc833cb1c65068a8defc684bf80b62f4287761d6a7a96842590ba454316e7f1`
- 每张卡包含固定 ID、风险域、摘要、建议、检索标签、官方 URL、版本和内容哈希。

加载器拒绝未知字段、重复 ID、非法 URL、非白名单官方域名和哈希不一致。运行时索引为内存 FTS5，建成后启用 `query_only`。快照更新必须离线构建、复核并重新评测，运行时不联网改库。

## 4. 隐私受限智能体

知识智能体只接收语义等级与类别、CPD 状态与起点、融合原因、基础动作、工作模式及冻结样本攻击族。原始 Prompt、suffix、Token 文本/ID、检索词、模型原始输出和隐藏推理均不得进入报告输入、API 响应、SQLite、日志或证据包。

存在有效 CPD 字符起点时，SafeQueryBuilder 只取起点前前缀；随后限制长度并脱敏 PEM、令牌赋值、Bearer、邮箱、IP 和长数字串。报告只允许 `summary`、`evidence_ids`、`handling_steps`、`limitations`；未知字段、未知引用、非法 JSON 或超时都回退到确定性模板。

## 5. 检索与报告配置

检索固定使用标签权重 2.0、词法权重 1.0、Top-3，同分按 `knowledge_id` 排序。知识模式为 `off`、`evidence`、`report`；任何模式都不能改变基础动作。

当前报告配置由开发集机械选择为 Qwen2.5-7B-Instruct、最多 64 个新 Token、5 秒边界。冻结报告实验只运行一次。其原始聚合中的动作不变率字段已被更正为 `legacy_unverified`，不能用于达标声明。

## 6. 三种平台内部工具

| 工具 | 平台内部效果 | 外部副作用 |
| --- | --- | --- |
| `gateway_enforcement` | 将不可变基础动作映射为平台网关状态回执 | 无 |
| `security_case` | 创建只含脱敏结构化事实的安全工单 | 无 |
| `evidence_bundle` | 生成规范 JSON、SHA-256 与下载回执 | 无 |

预览与执行分离，执行必须明确确认并携带 UUID 幂等键。同一 run、工具和幂等键只产生一次执行；首次返回 201，重放返回 200 和同一 `execution_id`。SQLite 使用事务和 `BEGIN IMMEDIATE` 处理跨连接竞争。证据包使用排序键、紧凑 JSON、ASCII 转义和结尾换行形成稳定字节，再计算 `sha256:<64 hex>`。写入边界强制 payload 实际摘要、artifact 声明摘要与 execution 回执摘要三方一致，下载时再次复算。

存储失败时返回固定脱敏错误，基础动作仍保持不变；工具不调用网络、子进程或平台外系统。

## 7. Web 与恢复

`/lab` 按证据到达顺序展示语义 Guard、Token 观测、Entropy-CPD、固定融合和知识检索。工具执行中心提供独立预览按钮、确认对话框、回执账本与证据下载。

页面只在 `sessionStorage` 保存脱敏 `run_id`。刷新后通过服务端 run 记录和 SQLite 恢复回执；场景、运行指标和 run 恢复使用独立失败边界，任一辅助接口失败不会阻断已有脱敏 run。标签页关闭后会话标识自动清除。桌面与移动端都使用可换行证据链，减少动效模式下停止持续旋转但保留文字忙碌状态。

运行指标将工具预览与已确认执行分开统计。“已验证执行动作保持率”只以 SQLite 中真实确认执行为分母；没有执行时显示 `N/A`。它用于观测平台内部执行是否保持存储动作，不等同于报告生成链路的独立动作不变性实验。

## 8. 创新与合规说明

本项目不把 FTS5、RAG、Qwen、CPD 或官方安全框架表述为原创算法。可辩护创新是隐私受限、动作单调的安全智能体编排：Token 起点约束检索范围，官方知识 ID 约束报告引用，明确确认和幂等执行产生可验证内部回执。

当前为自研 Web 平台和开源模型实现，不宣称已接入深信服平台或任何外部安全设备。参赛合规依赖赛事方允许自研平台替代的书面确认，仓库不保存私人聊天、账号或凭据。
