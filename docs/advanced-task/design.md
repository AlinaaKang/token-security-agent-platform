# 进阶任务系统设计：离线安全知识库与有依据研判

## 1. 目标与单一痛点

基础检测能够给出语义等级、CPD 异常起点和固定处置，但单独的检测结论缺少可核查的外部安全依据。进阶任务解决的单一痛点是：

> 在不泄露原始 Prompt 和攻击后缀、不改变基础检测动作的前提下，为每次安全研判返回可追溯的官方知识证据与引用。

本阶段不做在线爬取、自动改规则或反馈训练。外部资料更新属于后续受控流程。

## 2. 总体链路

```text
Prompt
  -> Qwen3Guard + Entropy-CPD + 固定融合
  -> 完整基础 AnalysisResult
  -> SafeQueryBuilder（截断、脱敏、固定路由标签）
  -> 本地 SQLite FTS5 Top-3
  -> 官方知识卡
  -> 严格 JSON 报告生成
  -> 引用校验
  -> 成功报告或确定性模板回退
```

知识层位于基础动作之后。它不能修改 `decision`、`detector_score`、`suspicious_span`、语义证据、基础 `latency_ms` 或处置动作。

## 3. 离线知识快照

- 版本：`official-v1`
- 卡片数：12
- 发布方：OWASP、MITRE、NIST
- 卡片文件 SHA-256：`05230ee8581ff8dd486c0d1d39cc54ce34b0e0e2b757fea19543ec1594e7e32c`
- MITRE ATLAS 数据版本：`2026.07`
- 每张卡包含固定 ID、风险域、摘要、指标、建议、检索标签、官方 URL、版本和内容哈希。

加载器拒绝未知字段、重复 ID、非法 URL、非白名单官方域名和哈希不一致。运行时索引为内存 FTS5，建成后设置 `PRAGMA query_only=ON`。

## 4. 安全查询边界

SafeQueryBuilder 的输入为原始 Prompt、可选 CPD 字符起点和归一化检测元数据。若存在有效异常起点，只使用起点前的前缀；随后最多保留 2048 字符，并脱敏 PEM、令牌赋值、Bearer、邮箱、IPv4/IPv6 和长数字串。

知识智能体只使用以下结构化事实：语义等级与类别、CPD 状态和起点、融合原因、基础动作、工作模式、冻结样本攻击族。检索查询被排除在 Pydantic 序列化和 `repr` 外，不进入 API、SQLite、日志或聚合报告。

## 5. 检索与报告

检索分数固定为：路由标签权重 2.0，词法权重 1.0；同分按 `knowledge_id` 排序，最多返回 3 条。测试集评测后不再调整权重或 fixture。

`report` 模式复用 Qwen2.5-7B runtime，但输入只有归一化事实和已检索知识卡。生成参数固定为确定性解码、最多 256 个新 Token、最多 3 秒。输出必须是单个 JSON 对象，只允许：

- `summary`
- `evidence_ids`
- `handling_steps`
- `limitations`

未知字段、代码围栏、前后缀文本、JSON 解析失败、重复/未知引用或超时均触发确定性模板报告。报告没有 `decision` 字段，引用必须来自本次 Top-3。

## 6. 三种工作模式

| 模式 | 行为 |
| --- | --- |
| `off` | 只运行基础检测，不检索、不生成 |
| `evidence` | 返回 Top-3 官方知识证据，不生成报告 |
| `report` | 返回证据并尝试生成严格引用报告，失败则模板回退 |

知识服务缺失或快照无效时，API 与基础模型仍可启动。响应明确标记 `unavailable` 或 `degraded`，不得假装知识层成功。

## 7. 审计与 Web

SQLite 只新增快照版本、知识模式/状态、最多 3 个知识卡 ID、报告状态和知识延迟。它不保存检索词、卡片正文、建议、报告正文或模型原始输出。

Web 使用三段式知识模式控制。知识证据位于 Token 风险轨道之后的独立全宽区域，展示发布方、标题、官方链接、建议和报告状态，并固定显示“知识证据不改变基础判定”。评测中心独立展示知识检索指标；事件页只展示快照版本与报告状态。

## 8. 创新边界

本项目不把 FTS5、RAG、Qwen、CPD 或官方安全框架表述为原创算法。进阶创新点是隐私受限、动作不变的安全智能体编排：将 Token 起点用于查询截断，把官方知识证据绑定到真实 `knowledge_id`，通过严格引用校验与确定性回退形成可审计闭环。
